## 🚀 **SETUP (2 MINUTES)**

### Step 1: Install
```bash
npm install
```

### Step 2: Setup .env
```bash
cp .env.example .env
```

### Step 3: Start MongoDB
```bash
mongod
```

### Step 4: Run JOSHVA
```bash
npm start
```

### Step 5: Open Browser
```
http://localhost:5000
```
