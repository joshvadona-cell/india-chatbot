# 🤖 JOSHVA - Simple AI Chatbot

## Quick Start (3 Steps)

### Step 1: Install
```bash
npm install
```

### Step 2: Run
```bash
npm start
```

### Step 3: Open
```
http://localhost:5000
```

**DONE! Enjoy JOSHVA! 🎉**
